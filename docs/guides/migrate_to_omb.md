# Migration Guide: dpdispatcher to oh-my-batch

CatFlow 0.6+ replaces `dpdispatcher` with [`oh-my-batch`](https://github.com/link89/oh-my-batch) for job submission and workflow management.

## Why oh-my-batch?

- **Built-in recovery**: `omb job submit --recovery` tracks job state in JSON — interrupted workflows resume where they left off
- **Declarative pipeline**: `omb combo` → `omb batch` → `omb job` replaces imperative Python submission code
- **Multi-scheduler**: SLURM / LSF / OpenPBS unified interface
- **Script-driven**: Workflow scripts run directly on HPC login nodes — no intermediate scheduler abstraction needed
- **Compatible with ai2-kit**: Same toolchain as the TESLA workflows

## What Changed

| Before | After |
|--------|-------|
| `dpdispatcher` | `oh-my-batch >= 0.6.0` |
| `dynaconf` | Pydantic config models |
| `ProcessPoolExecutor` + `Submission.run_submission()` | `WorkflowExecutor.run_script()` |
| `JobFactory` (dpdispatcher) | Script generation via `PmfBatchScript` / `TeslaBatchScript` |
| Manual checkpointing | `@apply_checkpoint` decorator from ai2-kit |

## New Config Format

```yaml
# machine.yml (new format)
machine:
  name: my-cluster
  scheduler: slurm
  resources:
    partition: gpu
    node_count: 1
    cpu_per_node: 4
    gpu_per_node: 1
```

## Enabling oh-my-batch for TESLA

The TESLA workflow defaults to `dpgen` for submission. To enable the oh-my-batch path:

```bash
export CATFLOW_USE_OMB=1
catflow tasker tesla param.json machine.json
```

## Using Checkpoints

```bash
# PMF with checkpointing — resume after interruption
catflow tasker pmf config.yaml --checkpoint .pmf_ckpt
```

All completed tasks are cached. Re-run the same command to resume.

## Generated Scripts

The Python layer generates bash scripts that call `omb` commands directly. Example:

```bash
# Generated by PmfBatchScript
omb combo \
  add_var COORDINATE 1.4 1.8 2.2 \
  add_var TEMPERATURE 300 500 700 \
  make_files ... --template ./input.inp.template \
  done

omb batch \
  add_work_dirs ./task.* \
  add_cmd 'cp2k.ssmp -i input.inp' \
  make ./batch-{i}.slurm --concurrency 4

omb job slurm submit ./batch-*.slurm \
  --max-tries 3 --wait --recovery pmf_recovery.json
```

## Quick Start

```bash
# Install
pip install oh-my-batch

# Run PMF workflow (new backend)
catflow tasker pmf config.yaml --checkpoint .ckpt

# Run PMF workflow (legacy dpdispatcher backend — still available)
catflow tasker pmf config.yaml
```
